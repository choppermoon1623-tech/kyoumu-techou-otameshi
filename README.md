# 電子教務手帳（お試し版）

https://choppermoon1623-tech.github.io/kyoumu-techou-otameshi/

[電子教務手帳](https://choppermoon1623-tech.github.io/kyoumu-techou/) を数日間ためしてもらうための版です。
**開いた瞬間から架空のダミーデータ**（架空の中学校・架空の教員・架空の生徒）が入っているので、
読み込みの手順なしにそのまま触れます。実在の人物・学校とは関係ありません。

## 触ってもらう人へ

- 入っている先生・生徒・時間割はすべて架空です。自由に触って構いません。
  画面左下（スマホは左上）の **ダミーに戻す** で、いつでも最初の状態に戻せます。
- 右上の **☁ ログイン** でGoogleアカウントにログインすると、**PCとスマホで同じデータ**になり、
  **QR提出チェック**も使えます。スマホでも**同じURL・同じアカウント**でログインしてください。
- 成績・名簿（生徒の氏名）は**クラウドに送りません**。その端末の中だけに保存されます。
  クラウドに上がるのは週の時間割・小テスト/提出物の予定と、QR提出チェックの
  クラス名・出席番号・提出時刻だけです。
- すでに本物の手帳データがあるアカウントでログインした場合は、**そちらのデータを読み込みます**。
  お試し版のダミーで上書きすることはありません。

## QR提出チェックを試す

1. PCで 成績 → 名簿 → **🏷 QRシール印刷**（試すだけならコピー用紙で可）
2. 小テスト・提出物の行の **📱 QR** で提出チェックを作る
3. スマホで [QR提出チェック](https://choppermoon1623-tech.github.io/submit-qr/) を開き、同じアカウントでログイン
4. シールを読み取ると、PC側にすぐ反映されます
